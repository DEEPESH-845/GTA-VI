## Chunk 3: Home Page — Hero Shard Animation

**Goal:** Enhance the hero section with 10 shard fragment images that animate on scroll.

### Files to Create/Modify

| Action | File |
|--------|------|
| Modify | `src/sections/Hero.jsx` — add shard layer system |
| Modify | `src/index.css` — add shard positioning classes |
| Create | `src/hooks/useShardAnimation.js` — GSAP shard animation hook |
| Public | `public/images/shard{0-9}.png` — user provides 10 shard PNGs |

### Implementation Details

1. **Shard Layer System**
   - Each shard is a `<picture>` element with `data-layer="true"` attribute
   - Positioned absolutely over the hero poster image
   - Each shard has `aria-hidden="true"` (decorative)
   - Layered with z-index stacking: poster at base, shards on top, logo at highest

2. **Shard Animation (GSAP ScrollTrigger)**
   - Create `useShardAnimation.js` hook that:
     - Registers 10 shard refs
     - On scroll, each shard translates/scalies independently
     - Shards start clustered (assembling the poster) and spread apart on scroll, OR
     - Start spread and assemble into the full poster on scroll (matching Rockstar's behavior where the poster fragments as you scroll down)
   - Animation properties per shard:
     - `x` translate: random range (-50px to 50px)
     - `y` translate: random range (-30px to 80px)
     - `scale`: range (0.8 to 1.2)
     - `rotation`: random range (-5deg to 5deg)
     - `opacity`: fade from 0 to 1
   - All scrubbed to scroll position with `scrub: 1`

3. **Shard Positioning (CSS)**
   - Each shard positioned `absolute` within the hero container
   - Responsive: use `object-fit: cover` and percentage-based positioning
   - Shards have transparent PNG backgrounds (fragmented pieces of the poster)

4. **Integration with Existing Hero**
   - Shards render inside the existing `.hero-section` container
   - The poster image remains as the base layer
   - Shards animate between poster and logo reveal
   - Play button and Coming Soon overlay remain on top

### Verification
- 10 shard images visible over the hero poster
- Scrolling causes shards to animate (translate, scale, rotate)
- Animation is smooth and scrubbed to scroll position
- Poster remains visible beneath shards
- Logo and CTAs remain clickable above shards
- Responsive on mobile/tablet/desktop

### Implementation Details

#### PromoCard.jsx (Reusable)
Each promo card follows the same pattern from the real site:

```
<button class="promo-card" aria-haspopup="dialog">
  <div class="promo-card-text">
    <q>Category Label</q>       <!-- e.g., "Videos", "People & Places", "Downloads" -->
    <h4>Section Title</h4>       <!-- e.g., "Trailer 2", "Only in Leonida" -->
    <p>Description text</p>
    <div class="cta-button">
      CTA Text + Arrow Icon      <!-- e.g., "Watch Now →", "Explore More →" -->
    </div>
  </div>
  <picture data-speed="0.97" data-scale="true">
    <source media="(portrait mobile)" />
    <source media="(landscape)" />
    <img fallback />
  </picture>
</button>
```

Props: `label`, `title`, `description`, `ctaText`, `ctaHref`, `mobileImage`, `desktopImage`, `onClick`

#### Card Behaviors
1. **Parallax**: Background images use `data-speed="0.97"` — GSAP ScrollTrigger translates Y at 97% scroll speed
2. **Scale**: Images scale slightly on scroll (`data-scale="true"`)
3. **Background trigger**: Each card can trigger a background color transition as it enters viewport (`data-trigger-background="true"`)
4. **Hover**: Subtle scale-down on hover (`scale-[0.98]`)
5. **Click**: Opens detail view or navigates to subpage

#### Four Cards on Home Page
1. **Ultimate Edition** → Opens detail modal/view
2. **Trailer 2** → Opens YouTube video modal (reusing existing modal pattern)
3. **Only in Leonida** → Navigates to `/only-in-leonida`
