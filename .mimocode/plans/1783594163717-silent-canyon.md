# Impeccable Init Plan — GTA VI Landing Page

## Context

This is a fan recreation of the GTA VI official website. It's a scroll-driven cinematic landing page built with React 19, Vite, Tailwind CSS 4, GSAP (ScrollTrigger), and Lenis smooth scrolling. The project has no `PRODUCT.md` or `DESIGN.md` yet — init needs to create them.

The impeccable skill scripts (`context.mjs`, `palette.mjs`, etc.) are not installed locally (`.agents/skills/impeccable/` doesn't exist), so we'll follow the skill's init instructions directly: create product context, document the design system, and surface next steps.

---

## What We'll Create

### 1. `PRODUCT.md` (project root)

Documents the project's identity, audience, register, and surface map so future impeccable commands have context.

**Contents:**
- **Project:** GTA VI Landing Page — fan recreation of Rockstar Games' official GTA VI site
- **Tech stack:** React 19, Vite 6, Tailwind CSS 4, GSAP ScrollTrigger, Lenis smooth scroll
- **Register:** `brand` — this is a brand/cinematic experience page, not an app/dashboard
- **Audience:** Gaming enthusiasts, web animation learners
- **Surfaces:** Single-page scroll experience with 9 sections (NavBar → Hero → FirstVideo → Jason → SecondVideo → Lucia → PostCard → Final → Outro)
- **Brand colors (already committed in CSS):** `#fff9cb` (yellow), `#ffb0c4` (pink), dark gradient backgrounds (`rgb(28,24,41)` → `rgb(17,17,23)`)
- **Fonts:** "Long" (display/headings), "Round" (body), "Round Bold" (extra bold accents)
- **Key assets:** 12 videos (output1-11.mp4, postcard-vd.mp4), ~40 SVG/PNG/WebP images

### 2. `DESIGN.md` (project root)

Documents the visual system so impeccable commands can apply it consistently.

**Contents:**
- **Theme:** Dark cinematic — black/deep purple body with pink-to-orange gradient accents
- **Color strategy:** Restrained — dark neutrals carry 80%+ of surface, yellow and pink as deliberate accent roles, gradient titles as the signature flourish
- **Typography system:** 3-font family (Long for display, Round for body, Round Bold for emphasis), sizes via clamp(), uppercase headings
- **Spacing:** Tailwind defaults, custom padding via component classes (py-40, lg:ps-40, etc.)
- **Z-index scale:** 100 (nav) → 90 (menu overlay) → 50 (hero mask elements) → 20 (entrance message) → 10 (hero mask) → 9999 (video modal)
- **Animation patterns:** GSAP ScrollTrigger with scrub timelines, pinned sections, video-scrub sync, mask reveals, opacity/scale transitions
- **Component patterns:** Section-level components, CSS module-like nesting via Tailwind `@layer components`
- **Responsive:** Mobile-first, breakpoints at xs (20rem), sm (40rem), md (768px), lg, xl, 2xl, 3xl

### 3. Color Palette Generation

The project already has committed brand colors in `index.css` (`--color-yellow: #fff9cb`, `--color-pink: #ffb0c4`). Per the impeccable instructions, since brand colors already exist in committed tokens, we **skip** the `palette.mjs` step and preserve identity.

The palette as-is:
- **Background:** Black → dark purple gradient (`rgb(17,17,23)` to `rgb(28,24,41)`)
- **Surface:** Dark gradient cards/overlays
- **Ink/Text:** White (`text-white`), `#e6e7ee` (menu items)
- **Accent primary:** `#fff9cb` (yellow — headings, highlights, image borders)
- **Accent secondary:** `#ffb0c4` (pink — subheadings, secondary highlights)
- **Gradient accent:** pink-400 → red-400 → orange-400 (the "Coming May 26th" title)

### 4. Next Steps Recommendations

After init completes, these are the highest-value next commands:

1. **`critique hero`** — The hero section is the most complex piece (mask animation, video modal, parallax). A UX critique would surface interaction and visual issues.
2. **`audit`** — Full-project technical quality check (a11y, responsive, performance). Several potential issues spotted during code review:
   - Missing alt text on many images
   - `hover:scale` transitions without `prefers-reduced-motion` handling
   - Lenis smooth scroll + GSAP scrub can conflict on mobile
   - Video modal lacks focus trap and Escape key handler
   - `will-change` only used in Final.jsx
3. **`polish`** — The gradient-title text has very tight letter-spacing; the navbar menu transition could be smoother; PostCard button has a typo class (`transation` instead of `transition`)
